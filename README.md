

# 🏦 Banking System Database (MySQL Project)

### 📋 Overview
This project is a **SQL-based Banking System** designed to simulate core operations of a bank — including **customer management, account handling, transactions, and fund transfers**.  
It demonstrates database creation, normalization, and real-world analytical queries using **MySQL**.

---

## 🧠 Objectives
- Build a **relational database** for a banking system.
- Perform **CRUD operations** and advanced **SQL queries**.
- Demonstrate **joins, subqueries, window functions, and transactions**.
- Showcase **data integrity** using relationships and constraints.
